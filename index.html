    How it's built

    One site, three independent projects

    This page is static and hosted on GitHub Pages. Each project lives in its own folder with its own backend, deployed separately, so one can change without breaking the others.

    Replays always work

    Every project ships a recorded run, so you can see it work even when a live backend is asleep. Live demos go through a rate-limited proxy, and no API keys ever reach the browser.

    Measured, not claimed

    Each project reports its numbers: retrieval accuracy, agent token cost, and serving latency and cost per token.
